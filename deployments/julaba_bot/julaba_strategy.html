🎓 PhD-Level Mathematical Analysis (12 Components)

Each component is weighted and contributes to a final score of 0-100. Minimum score of 55 required for trade approval.

📈
Trend Strength (SMA)
dist = |price - SMA40| / SMA40
Measures price distance from 40-period SMA. Strong trend = larger distance.
Weight: 15%
📊
Volume Confirmation
ratio = volume / SMA(volume, 20)
Confirms breakouts with above-average volume. Ratio ≥ 1.5 = strong.
Weight: 10%
⚡
Momentum (RSI)
score = |RSI - 50| / 50
Strong momentum when RSI far from neutral 50. Penalizes extremes (>80, <20).
Weight: 12%
🎯
Risk:Reward Ratio
R:R = potential_profit / stop_loss
Minimum 2:1 required. Score scales up to 5:1 for maximum points.
Weight: 12%
🌊
Volatility Regime
ATR% = ATR / price × 100
Optimal range: 0.3% - 2.0%. Too low = no opportunity, too high = risky.
Weight: 8%
💪
ADX Strength
score = min(ADX/35, 1.0)
ADX ≥ 25 = trending. ADX ≥ 35 = strong trend (max score).
Weight: 8%
📐
Linear Regression R²
R² = 1 - (SS_res / SS_tot)
Measures trend reliability. R² ≥ 0.7 = strong linear trend.
Weight: 8%
🔮
Hurst Exponent
H = log(R/S) / log(n)
H > 0.5 = trending (momentum). H < 0.5 = mean-reverting. H ≈ 0.5 = random.
Weight: 7%
📉
Z-Score (Mean Reversion)
Z = (price - μ) / σ
|Z| > 2 indicates potential mean reversion opportunity.
Weight: 5%
🔄
Autocorrelation
ACF = Σ(x_t - μ)(x_{t-1} - μ) / σ²
High ACF = predictable continuation. Measures market memory.
Weight: 5%
⚠️
Skewness/Kurtosis
Tail Risk Assessment
High kurtosis = fat tails (extreme moves). Penalizes during high tail risk.
Weight: 5%
💰
Kelly Criterion
K = (p × b - q) / b
Optimal position sizing. K > 0 required. Half-Kelly used for safety.
Weight: 5%
Final Score Calculation
final_score = Σ(component_score × weight)
APPROVE if score ≥ 55
OVERRIDE AI if score ≥ 65
PROACTIVE TRADE if score ≥ 70
OVERRIDE AI VETO if score ≥ 80

🛡️ Mathematical Command Validation (Double-Layer)

All settings changes require explicit user intent. AI cannot accidentally modify system parameters.

Layer 1: MATH GUARD (ai_filter.py)

Strips unauthorized command blocks from AI responses before they reach execution layer.

Layer 2: Intent Validation (telegram_bot.py)

Validates user message against command action before execution.

❌ BLOCKED (Never Execute)

  • okay → Acknowledgement, not command
  • got it → Acknowledgement, not command
  • what is the risk? → Question, not command
  • how does mode work? → Question, not command
  • good → Acknowledgement, not command
  • thanks → Acknowledgement, not command

✅ ALLOWED (Execute Command)

  • change risk to 2% → Action verb + target + value
  • set confidence to 80% → Action verb + target + value
  • switch to BTC → Action verb + symbol
  • open long → Trade action + side
  • pause the bot → Explicit pause request
  • resume trading → Explicit resume request
Command Type Required User Intent Example
set_param Action verb + parameter name + value "change risk to 1.5%"
open_trade Trade keywords: open, buy, long, short "open a long position"
close_trade Close keywords: close, exit, sell "close the position"
