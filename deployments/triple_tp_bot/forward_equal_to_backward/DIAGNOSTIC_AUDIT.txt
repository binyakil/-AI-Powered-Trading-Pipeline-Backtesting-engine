ROOT CAUSE SYNTHESIS
================================================================================

The 10x trade frequency divergence is NOT a CODE BUG.

It's a COMPOUNDING EFFECT:

  1. CLOCK DRIFT (Critical):
     Different 3m bar boundaries → Different lookback candles
     
  2. NOISE SENSITIVITY (High):
     RSI(6) on MEXC noise → 10x more threshold crossings than Kraken
     
  3. NO DEBOUNCE (High):
     CONFLICT_MODE="hedged" + no MIN_ENTRY_INTERVAL
     Every signal = immediate trade, no rate limiting
     
  4. DATA REGIME MISMATCH (High):
     Backtest optimized on smooth data
     Live uses noisy data
     Parameters unchanged → Hypersensitivity to noise

Combined effect: 3.6x observed multiplier with potential to spike higher.
