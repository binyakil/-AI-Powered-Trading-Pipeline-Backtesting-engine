## Column Definitions

| Column | Type | Description |

| `trade_id` | String | Unique trade identifier (T1, T2, ..., T200) |

| `exit_time` | DateTime | UTC timestamp when trade was closed |
| `exit_px` | Float | Exit price (last TP fill or stop hit) |
| `exit_reason` | String | Reason for exit (e.g., TP1_CLOSED_SL, TP1_FILLED, TRAIL_ARMED) |
| `R_result` | Float | Risk-Reward result in R units (P&L / Risk Distance) |

## Data Extraction Process

The CSV was generated by parsing the bot.log file (3.7M lines) and extracting:

1. **Entry Events**: Identified by "DRY-RUN entry" log lines
   - Captures: trade_id, side, entry_price, stop_price, position_size

2. **TP Fill Events**: Identified by "TP{n}_FILLED" log lines
   - Captures: which TP level (1/2/3) was filled and at what price

3. **Trail Armed Events**: Identified by "TRAIL_ARMED reason=" log lines
   - Captures: exit reason (reason for closing the trade)

4. **Close Events**: Identified by "Trade {id} closed PnL=" log lines
   - Captures: exit_time, actual_pnl, closes the trade record

5. **Calculations**:
   - **TP Prices**: Calculated from entry_price ± (stop_distance × R_multiple)
   - **R_Result**: Computed as PnL / |entry_price - stop_price|
   - **Exit Price**: Inferred from TP fill prices in the log

## Notes

1. **R_Result Meaning**:
   - Positive value = winning trade (gain multiple of risk)
   - Negative value = losing trade (loss multiple of risk)
   - Example: 2.5R = won 2.5 times the risk amount

2. **Exit Reason Codes**:
   - `TP1_FILLED` = Stop loss hit, trail activated
   - `TP1_CLOSED_SL` = First TP filled, remaining position closed on SL
   - `TRAIL_ARMED` = Trade closed via trailing stop mechanism
   - Empty = Trade closed at final position

3. **Data Gaps**:
   - Some exit_px values may be empty if exit occurred via stop loss (not TP fill)
   - exit_reason may be empty for some trades (logged as TRAIL_ARMED)

4. **Accuracy**:
